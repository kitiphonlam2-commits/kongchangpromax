รายการโครงการที่จะออกหนังสือ:

ซิงก์ข้อมูลออนไลน์ข้ามเครื่อง (เห็นตรงกันทุกเครื่อง)

ยังไม่ได้เชื่อมต่อ Google Apps Script
ข้อมูลจะเก็บเฉพาะในเบราว์เซอร์เครื่องนี้จนกว่าจะใส่ลิงก์ Web App (/exec)
เคล็ดลับ: นำลิงก์เดียวกันไปวางในตัวแปร DEFAULT_CLOUD_SYNC_URL ในโค้ด HTML ก่อนขึ้น GitHub Pages เพื่อให้ทุกเครื่องเชื่อมให้อัตโนมัติ

โค้ด Google Apps Script (วางใน script.google.com)

  1. เปิด script.google.com → สร้างโปรเจกต์ใหม่ (เช่น KongchangProjectsSync) แล้ววางโค้ดด้านล่าง
  2. กด Deploy (ทำให้ใช้งานได้) → New deployment → เลือกประเภท Web app
  3. ตั้งค่า Execute as: Me (ตัวฉัน) และ Who has access: Anyone (ทุกคน) → กด Deploy และอนุญาตสิทธิ์
  4. คัดลอกลิงก์ Web app (ลงท้ายด้วย /exec) มาวางในช่องด้านบน หรือวางใน DEFAULT_CLOUD_SYNC_URL ในไฟล์ HTML
